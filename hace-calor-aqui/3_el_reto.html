3. El reto

Ha llegado el momento de poner en macha el proyecto para medir el calor en el aula. Vais a programar la placa EchidnaBlack2 para que registre la temperatura cada cierto tiempo para crear una gráfica de temperaturas.

Después, tendréis que pensar qué cambios podríais hacer para mejorarla: ¿y si abrimos las ventanas en otro momento?, ¿cambiamos las mesas de sitio?, ¿ponemos plantas o cortinas? Aplicad estos cambios y volved a medir.

Con los datos que obtengáis, crearéis gráficas y podréis analizar científicamente qué opción funciona mejor.
¡Vamos a usar la tecnología para cuidar de nuestro bienestar!

3.1 ¡Programamos!

Un fondo para la gráfica

Para poder ver gráficamente la medida de la temperatura a lo largo del la jornada puedes usar este fondo de pantalla en el que vienen las diferentes temperaturas. Para que se vea mejor, las líneas están un poco separadas entre sí, así que tendremos que hacer una pequeña operación matemática para que todo funcione perfectamente, pero no te preocupes, eso lo veremos más ademante.

En este vídeo puedes ver cómo subir el fondeo de pantalla, que puedes descargar haciendo clic aquí.

Operación para adaptar el gráfico

Para que el gato de Scratch marque la temperatura vamos a hacer que se desplace hacia arriba o hacia abajo (eje y). Para esto, primero reducimos el tamaño del gato a 10, y usamos el bloque "Dar  y el valor ...", en el que el valor será la lectura del sensor (figura 1). Esto va a hacer que el gatito suba o baje con la temperatura, pero cambiará solo un paso o pixel por cada grado. Como esto es muy poco para poder diferenciarlo bien, la escala del fondo se ha hecho con las lineas de cada grado separadas 4 pasos o píxeles. Por eso, para que el gato vaya al punto correcto, tendremos que multiplicar el valor por 4 (figura 2).

Dibujando la gráfica

Es momento de dibujar la gráfica. Ya sabes cómo desplazar al gato a la altura correcta para marcar la temperatura. Ahora hay que hacer que dibuje la gráfica. para esto:

  1. Tendremos que agregar los bloques de Lápiz.
  2. Primero pondremos un bloque de borrar, por si hay algo dibujado.
  3. También pondremos un bloque de levantar el lápiz, para que deje de pinta si estaba haciéndolo.
  4. Después desplazaremos al gato al punto de inicio.
  5. Luego bajaremos el lápiz para empezar a pintar la gráfica.
  6. Por último, haremos que el gato se desplace al punto que indique la temperatura en el eje y un paso o pixel hacia la derecha en el eje x cada cierto tiempo.

Puedes hacerlo ordenando estos bloques. en la siguiente imagen podrás ver el programa completo, pero es mejor que lo intentes antes sin mirar.

3.2 Plan de investigación

Ya tenemos nuestro dispositivo para medir la temperatura listo, pero… ¿cómo vamos a usarlo?

Antes de empezar a recoger datos, necesitamos pensar como verdaderos científicos y científicas: hay que diseñar un buen plan. Eso significa decidir cuándo vamos a medir (¿cada hora? ¿cada 30 minutos? ¿cada 10?), dónde colocaremos la placa EchidnaBlack2, etc.

Después, toca imaginar y poner en práctica algunas ideas para bajar la temperatura del aula: mover las mesas, abrir o cerrar ventanas, poner carteles en las ventanas, usar plantas, colgar cortinas… ¡lo que se os ocurra!

También debéis pensar si aplicar las medidas y tomar datos de temperatura durante todo un día antes de probar otra solución o si es mejor probar varias el mismo día.

Y lo más importante: vamos a comparar los resultados. Gracias a las gráficas, veremos qué soluciones han funcionado mejor.
